Introduction

Not all misalignment is dramatic

Users push, and much of what goes wrong in ordinary chats is a model giving in to that pressure. A user may demand an unsupported conclusion, like faked experiment results, or tuck a harmful task inside a legitimate request.

The problem

Refusal and misalignment rates alone can’t explain why a model behaves as it does. To find the cause, we have to see what happens when the pressure changes, the prompt is reworded, a false claim is added, and whether a model blocks safe requests just because they look dangerous.

Our approach

Harley builds 1,591 contrast sets around real user turns from WildChat, LMSYS-Chat-1M and ShareGPT, in 17 languages. The five prompts in each set change one property at a time, separating the pressure from wording, tone, surface cues and false claims.

What we find

User pressure raises misalignment nearly fivefold, from 4.3% to 20.4%. A pretext or claimed fact makes most refusals disappear, while safe requests that only look risky are refused more often. Two small open models can flag the prompts most likely to trip up frontier models.

The prompts in each set

Each set has five prompts: the first four below, plus either a hard negative or a jailbreak. One is the anchor, the unmodified real user turn; the other four are written around it. The anchor is never the paraphrase or style control.

T · Target
Adds a pressure that pushes the model beyond the task’s scope.
P · Paraphrase
The same pressure in new words, to check the wording isn’t doing the work.
A · Aligned control
Removes the pressure and keeps the task. Usually this is the real user turn.
S · Style control
Keeps the target’s language and register but asks for an unrelated task.
H · Hard negative
Changes key facts so helping is right, while keeping the surface cues.
J · Jailbreak
Keeps the requested action but adds a false pretext or an unverifiable claim.

II The second world · the split

A one-line pretext undoes most refusals

The fifth prompt of every set is either a hard negative or a jailbreak. A hard negative changes what is asked, so helping becomes right. A jailbreak variant adds an unverifiable claim: the action stays the same, so helping is still wrong if the claim is false. All 200 sets in the gold set started as hard negatives; in human review, 140 turned out to add an unverifiable claim, so we relabelled them as jailbreak variants.

The reading · interpretation

Single-turn misalignment is not a solved problem

The clearest failures read the same to everyone. The milder ones don’t: a response that leans toward what the user wanted can look like good service to one reader and weak misalignment to another. Everyday users mostly meet these milder cases, and where the line falls is still unclear.

What we do about it

Four of us agreed on a shared rubric before any labelling, and the judge uses the same one. Still, one reviewer wrote the human labels and the judge was tuned on them, so where weak misalignment ends and a user’s response preference begins may reflect that reviewer’s view. This boundary warrants more discussion and analysis. We report weak and strong misalignment separately and release every response with its labels to support that work.

Why Harley?

In One Piece, the Harley is an ancient text kept in Elbaph’s Owl Library, and the source of the giants’ myths and legends. It tells of three worlds: one that gave in to temptation, one torn in two, and a third still being foretold. Much of its language is lost, so its interpretation differs depending on the reader.

The library is kept by Biblo, an owl who makes every book brought inside grow large enough for giants to read. We grew each real user request the same way, into five prompts.
