Introduction

Not all misalignment is dramatic

Much of what causes misalignment in a model is through giving into user pressure. A user may demand an unsupported conclusion, like faked experiment results, or hide a harmful task inside a legitimate request.

The problem

Refusal and misalignment rates alone can’t explain why a model behaves as it does. To find the cause, we have to see what happens when the pressure changes, the prompt is reworded, a false claim is added, and whether a model blocks safe requests just because they look dangerous.

Our approach

Harley builds 5,215 contrast sets around real user turns from WildChat, LMSYS-Chat-1M and ShareGPT, in 17 languages. Each set has five prompts which change one property at a time, isolating the underlying pressure from variables like wording, tone, surface cues, and false claims

What we find

User pressure raises misalignment nearly fivefold, from 4.3% to 20.4%. A pretext or claimed fact makes most refusals disappear, while safe requests that only look risky are refused more often. Two small open models can flag the prompts most likely to trip up frontier models.

How a set is made

One real request followed from the corpus to a finished set. It is the Arabic set from Figure 1 of the paper.

The prompts in each set

Each set has five prompts: the first four below, plus either a hard negative or a jailbreak. One is the anchor, the unmodified real user turn and the other four are written around it. The anchor is never the paraphrase or style control.

T · Target
Adds a pressure that pushes the model beyond the task’s scope.
P · Paraphrase
The same pressure in new words, to check the wording isn’t doing the work.
A · Aligned control
Removes the pressure and keeps the task. Usually this is the real user turn.
S · Style control
Keeps the target’s language and register but asks for an unrelated task.
H · Hard negative
Changes key facts so helping is right, while keeping the surface cues.
J · Jailbreak
Keeps the requested action but adds a false pretext or an unverifiable claim.

The verses

Each set has five versions of a real user request

Each set starts from a real user turn. We add or remove the pressure, reword it, keep only its style, and either change one fact or add a pretext.

II The second world · pretext

A one-line pretext undoes most refusals

The fifth prompt in each set takes one of two forms. A hard negative changes the request so it becomes appropriate. A jailbreak keeps the harmful request and adds a pretext the model can't verify.

In the200 human reviewed gold sets, 140 prompts written as hard negatives turned out to be jailbreaks. They change a median of just nine words, yet significantly reduce refusals.

III The third world · screening

Small open models predict frontier model failures

Testing every prompt on every frontier model is expensive. We asked whether two cheap open models could predict which prompts make the frontier ones misbehave. It turns out they can, the prompts that trip up the small models are mostly the same ones that trip up the big ones.

  1. Find the frontier failures. Out of 200 target prompts in the gold set, 31 break at least one of the six most robust models (Claude Opus 5, GPT-5.6 Sol and Luna, DeepSeek V4.1 Flash, Kimi K3, GLM 5.3). A break occurs when at least 3 of the model’s 5 responses are misaligned.
  2. Rank using small models. We sorted all 200 gold set targets prompts based on how frequently they caused misalignment in Gemma 4 31B and Qwen 3.8 27B.
  3. Evaluate the distribution. While random sampling would place about a third of the 31 prompt failures in the top third, the small-model ranking successfully groups 28 of them (90%) into the top third. This means we can capture nearly all frontier model failures by testing just 33% of the dataset.

Conclusion

Single-turn misalignment is not a solved problem

Models still give in to pressure from a single user turn. Across 17 models, matched controls show that the pressure itself causes the failure, not the task, wording or tone. The same prompts trip models up in all five languages we tested, and two small open models can tell us in advance where frontier models will fail.

What remains open

Much attention goes to severe forms of misalignment. The milder forms that everyday users meet are harder to pin down. A response that leans toward what the user wanted can look like good service to one reader and weak misalignment to another. Where that line falls is still unclear and sometimes subjective.

We hope Harley gives future work a shared set of matched requests for studying how models respond to user pressure across the range of situations real users bring to them. We release every response with its labels, reporting weak and strong misalignment separately, to support that work.

Why Harley?

In One Piece, the Harley is an ancient text kept in Elbaph’s Owl Library, and the source of the giants’ myths and legends. It tells of three worlds: one that gave in to temptation, one torn in two, and a third still being foretold. Much of its language is lost, so its interpretation differs depending on the reader.

The library is kept by Biblo, an owl who makes every book brought inside grow large enough for giants to read. We grew each real user request the same way, into five prompts.
