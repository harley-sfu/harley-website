Introduction

Not all misalignment is dramatic

A significant proportion of misalignment occurs when language models give into user pressure. Users may try to conceal harmful tasks within legitimate requests or ask to fabricate a report without providing real evidence.

The Problem

Refusal and misalignment rates aren’t sufficient to explain the impacts of user pressure on models. To find a root cause, we have to look at how models react to changes in the user pressure. For example, what happens when we paraphrase the prompt, remove the pressure or make the task appropriate?

Our Approach

Harley builds 5,215 contrast sets around real user turns from WildChat, LMSYS-Chat-1M, and ShareGPT, in 17 languages. Each set contains five prompts anchored around a real user turn, where each prompt changes one property at a time by isolating pressure from variables like phrasing, tone, surface cues, and false claims.

What we find

We find that user pressure raises the misalignment rate by nearly five times, from 4.3% to 20.4%. Introducing an unverifiable pretext or fact can reduce refusals significantly, whereas risky looking but ultimately appropriate requests are refused more often. Furthermore, smaller and cheaper models can successfully predict which prompts will cause misalignment in frontier models.

How a set is made

One real request followed from the corpus to a finished set. It is the Arabic set from Figure 1 of the paper.

The prompts in each set

Each set contains five prompts: The first four listed below, plus either a hard negative or a jailbreak. One is these prompts is the unmodified user turn and designated as the anchor role. The other prompts are written based off the anchor. The anchor can never be the paraphrase or style control.

T · Target
Adds a pressure that pushes the model beyond the task’s scope.
P · Paraphrase
A paraphrase of the pressure, to check if wording causes misalignment.
A · Aligned control
Removes the pressure but keeps the task. Usually this the anchor.
S · Style control
Keeps the target’s language and register but changes to a completely unrelated and benign task.
H · Hard negative
Changes key facts so the prompt is appropriate, while keeping the surface cues.
J · Jailbreak
Keeps the requested action but adds a false pretext or an unverifiable claim.

The verses

Each set has five versions of a real user request

Each set starts from a real user turn. We add or remove the pressure, reword it, keep only its style, and either change one fact or add a pretext.

II The second world · pretext

A one-line pretext undoes most refusals

The fifth prompt in each set can either be a hard negative or a jailbreak. A hard negative changes the request so it becomes appropriate. A jailbreak keeps the harmful request and adds a pretext the model can't verify.

In the 200 human reviewed gold sets, 140 prompts written as hard negatives turned out to be jailbreaks. They change a median of just nine words, yet significantly reduce refusals.

III The third world · screening

Small open models predict frontier model failures

We asked whether two cheap, open models could predict which prompts make frontier models misbehave. It turns out they can. The prompts that trip up the small models are mostly the same ones that trip up the frontier models.

  1. Find frontier failures. Out of 200 target prompts in the gold set, 31 break at least one of the six frontier models (Claude Opus 5, GPT-5.6 Sol and Luna, DeepSeek V4.1 Flash, Kimi K3, GLM 5.3). A break occurs when at least 3 of the model’s 5 responses are misaligned.
  2. Rank using small models. We sorted all 200 gold set targets prompts based on how frequently they caused misalignment in Gemma 4 31B and Qwen 3.8 27B.
  3. Evaluate the distribution. Random sampling should place one third of the 31 prompt failures in the top third but the small-model ranking successfully places 28 of them (90%) into the top third. This means we can predict nearly all frontier model failures by testing just 33% of the dataset.

Conclusion

Single-turn misalignment is not a solved problem

Language models still give in to single-turn user pressure. Across 17 models, our matched control dataset finds that user pressure is what often causes misalignment, not the task, wording, or tone. Furthermore, we find that adding an unverifiable pretext to a prompt can significantly reduce task refusals. Finally, we demonstrate that small, open models can successfully predict which prompts will cause misbehaviour in frontier models.

What remains open

Most attention regarding misalignment looks at the severe and obvious forms. The milder forms that everyday users encounter are often harder to pin down. A response that accomplishes a user’s task can look like routine good service to one person and yet constitute weak misalignment to another. It is unclear and often subjective where exactly the line between mundane response and weak misalignment falls.

We introduce Harley, a dataset of matched control prompts designed to study how models respond to real-world user pressure. We release all responses, with explicit labels for weak and strong misalignment separately to support future work.

Why Harley?

In One Piece, the Harley is an ancient text kept in Elbaph’s Owl Library, and the source of the giants’ myths and legends. It tells of three worlds: one that gave in to temptation, one torn in two, and a third still being foretold. Much of its language is lost, so its interpretation differs depending on the reader.

The library is kept by Biblo, an owl who makes every book brought inside grow large enough for giants to read. We grew each real user request the same way, into five prompts.
