Lab · hero visual samples

Three ways to read the rings

Each sample uses the real counts: 1,591 contrast sets in 17 languages, 200 of them human-reviewed (gold). They are all meant to be played with, which the paper and code can't offer. Hover or tap anything. Every chart can also be focused with Tab and stepped through with the arrow keys.

Sample A

The rings, with a guide

The current rings, plus a legend, names you can turn on, a readout that stays put, and a short guided tour for first-time readers.

  • Gold set · human-reviewed
  • Silver set · model-reviewed

  • Click a ring to pin it, and click the empty space to let go.
  • "Gold only" shows that every reviewed set sits on the ten inner rings.

Sample B

Unroll the rings

The rings straighten out into a ranked bar chart and roll back up again. Each tick slides to its spot, so readers see that the pretty picture and the plain chart hold the same data.

  • Gold set · human-reviewed
  • Silver set · model-reviewed

  • Drag the slider slowly: the gold ticks gather at the start of each bar.
  • Hovering works halfway through too, so you can follow one ring as it unrolls.

Sample C

One dot per set, three views

All 1,591 sets as dots that fly between views. The trunk keeps the tree-ring look, the islands compare languages, and the gold/silver view shows where each language's reviewed sets went.

  • Gold set · human-reviewed
  • Silver set · model-reviewed

  • Hover Korean in the trunk, then switch views: its dots stay lit as they move.
  • In "Gold vs silver", the gold pile is made of only ten languages.
